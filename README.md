# NORÉA Website Starter

This is a premium static ecommerce website starter for NORÉA using the campaign images created in this chat.

## What is included

- `index.html` — the full website page
- `styles.css` — responsive luxury activewear styling
- `app.js` — products, filters, quick view, cart drawer and WhatsApp checkout demo
- `assets/images/` — optimized WebP campaign images

## How to open it

1. Unzip the folder.
2. Open `index.html` in your browser.

## Important next edits

- Replace the WhatsApp number in `app.js`: search for `263000000000` and put your real business WhatsApp number.
- Change prices, product names and categories in the `products` array inside `app.js`.
- Add payment processing later with Stripe, PayPal, Paynow, Paystack or your preferred provider.
- Add a backend/admin dashboard later for real orders, inventory, customer accounts and delivery zones.

## Brand direction used

- Logo text: NORÉA
- Tone: premium, clean, African activewear campaign style
- Colors: warm beige, black, white, pink, grey
- Layout: mobile-first ecommerce with lookbook and product-grid sections

Created images included: 64 optimized assets.
